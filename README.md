# Computational Workflows for Engineers

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-nd/4.0/)

An open educational resource teaching engineering students to build complete data products through systematic computational workflows. This book moves students from foundational computer literacy to professional-grade data engineering, emphasizing command-line proficiency, version control, SQL databases, Python automation, and building systems that serve real end users.

Students learn to work at lower levels of abstraction-mastering the command line, writing SQL queries, automating workflows-precisely so they can build higher-level interfaces that make data accessible and useful to others. Whether the final product is an automated Excel dashboard, an interactive Quarto report, or a live web application, the focus remains on engineering discipline, reproducibility, and treating computational work as craft.

**Key Topics:**

- Foundational computer concepts and file systems
- Command-line proficiency and version control with Git
- Data engineering with SQL and DuckDB for analytical workloads
- Python for scripting, automation, and workflow orchestration
- Professional development practices and modern tooling
- Building complete data pipelines from ingestion through presentation
